# ChladniPlate
DIY Chladni plate (metal plate, transducer, signal generator) that visualizes sound as sand patterns, plus custom software generating unique nodal patterns from frequencies via wave-equation math (Chladni modes, Bessel functions), with mode blending &amp; animated sweeps.
